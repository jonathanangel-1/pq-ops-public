# Public data boundary

This repository is a separate public edition with fresh Git history. The operational repository and its history were not imported.

## Included

- Application interfaces, business logic, integration adapters, API routes, database schemas, and security controls.
- Synthetic examples and selected sanitized regression tests.
- Credential-free local demonstrations and configuration variable names.

## Replaced or excluded

- Real contact details, business registration identifiers, banking details, shipment identifiers, message IDs, internal hosts, and account associations were replaced with synthetic values.
- Original documents, personal photos, mailbox exports, production snapshots, local caches, environment files, deployment linkage, and operational logs were excluded.
- Historical replay archives containing copied business records were excluded. Independent fictional scenarios exercise the public workflows instead.
- Angie profile measurements, purchase outcomes, products, personal notes, and image data were regenerated from fictional records.

The demos never send communications or mutate company systems. A demonstration result is not a provider verification or a live operational claim. Real integration implementations remain in the source; using them requires separately configured services and credentials.

Future updates should export reviewed files into this public edition. Do not merge the private repository history or copy environment files, live snapshots, or historical replay archives into it.
